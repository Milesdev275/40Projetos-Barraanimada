# 40Projetos-Barraanimada

Barra de navegação com ícones e efeitos visuais em CSS. Este exercício faz parte da minha sequência de estudos de desenvolvimento web.

## Tecnologias

HTML e CSS.

## Como acessar

1. Baixe os arquivos em Code → Download ZIP ou clone o repositório.
2. Mantenha os arquivos juntos e abra index.html no navegador.

## Organização

- index.html: estrutura da barra e seus links.
- style.css: cores, posicionamento e efeitos de interação.
